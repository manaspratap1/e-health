4️⃣ High-Level Flow (Patient Example)

Patient visits site → login/register → JWT issued by Auth Service

API Gateway validates JWT → routes requests to services

Patient updates profile → Patient Service updates DB

Patient searches doctor → Doctor Service returns list

Patient books appointment → Appointment Service creates record

On scheduled time → Video consultation via WebRTC service

Doctor adds prescription → Prescription Service saves record

Patient can view prescription & download

Doctor flow is the mirror: accepts appointments, consults, prescribes
